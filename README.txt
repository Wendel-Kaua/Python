#  RPG

Um jogo de RPG baseado em texto feito em Python para ser jogado via terminal/console.

---

## Funcionalidades do Jogo

* **Criar Personagem:** Define o nome do seu herói para dar início à aventura.
* **Ver Personagem:** Exibe os status do jogador (Nome, Nível, XP, Vida, Força, Defesa e Ouro).
* **Sistema de Treino:** Ganhe **+10 XP** e **+1 de Força** a cada sessão de treino.
* **Sistema de Level Up:** Ao atingir 50 de XP, o jogador sobe de nível, recupera/aumenta a vida máxima e zera o XP atual.
* **Menu Interativo:** Navegação com tratamento de erros de digitação e pausa para leitura dos dados.

---

## Como Executar

### Pré-requisitos

* Ter o **Python 3.x** instalado em sua máquina.

### Passos

1. Faça o download ou clone este repositório.
2. Abra o terminal ou prompt de comando na pasta onde o arquivo `.py` está salvo.
3. Execute o comando:

```bash
python nome_do_arquivo.py

```
